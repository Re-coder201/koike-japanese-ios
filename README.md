# 小池の专属日语学习软件

简洁可爱的日系 iPhone 学习初版，版本 0.1.0。沿用英语软件苹果端的 PWA 安装方式：Safari 打开 HTTPS 网址，分享 → 添加到主屏幕。这不是需要签名的 IPA。

## 已实现

- 搜索：日语、假名、片假名、罗马音、中文；本地自编入门词库；单词及例句的设备日语朗读；查词计数。
- 搜索框聚焦后背景模糊，显示历史；单条 × 删除；设置可关闭历史显示。
- 收藏：心形收藏，综合得分、收藏时间、五十音排序；可调排序权重。
- 复习：收藏词随机抽取，纯单词和例句模式；认识／不认识后显示答案；记错了、下一个、上一题；回看不重复计分。
- 阅读：真实日语 RSS 标题与原文链接，幽默、时政、历史、文化、生活分类，标题搜索，文章收藏，以及日语网络搜索入口。
- 本地数据：学习记录自动保存，JSON 导出／导入，应用缓存和更新。

## 初版范围

词库为自编入门词汇与教学例句，不是完整日语词典。未命中可打开在线词典；变形词暂不自动还原。日语发音依赖 iPhone 已安装的日语语音。未接入可靠 JLPT 真题统计，频次为 0，不把自编例句标为真题。暂无全文抓取、假名标注、全文翻译或离线语音模型。文章在来源网站打开；离线可用的是应用页面、入门词库和已缓存索引。

收藏排序保留英语版默认比例：查词次数×0.5 + 真题频次×0.3 +（不认识次数+记错次数）×0.2。两次不同的用户行为“不认识”和“记错了”分别计数；回看同一题不会再计数。

## GitHub 上传与发布

将本目录内容放在新仓库根目录，包含隐藏的 `.github` 目录。不要上传最外层文件夹作为第二层目录。

1. 默认分支设为 `main`。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
3. Actions → **Publish iPhone app** → Run workflow；绿色通过后在 Deployments 或 Pages 中打开发布网址。
4. iPhone Safari 打开网址，分享 → 添加到主屏幕。
5. 更新时上传替换文件；应用版本变更需同时修改 `sw.js` 的 `CACHE` 名称。旧窗口全部关闭后再次打开以激活新版本。

文章刷新工作流每天 UTC 00:17（北京时间 08:17）运行，也可手动执行 **Refresh Japanese articles**。需要允许仓库 Actions 写入代码及执行工作流。仓库没有 Pages 权限时不会自动发布，需要仓库拥有者启用。GitHub 定时任务可能延迟，长时间不活跃的仓库可能被暂停计划执行。

## 本地开发与验证

无需 npm 依赖。

```sh
python -m http.server 8080
node tools/test.cjs
python tools/update_articles.py
```

通过 `http://localhost:8080` 预览。Service Worker 需要 localhost 或 HTTPS，不能直接双击 HTML 验证离线安装。

## 来源与数据

- 幽默文章索引：[デイリーポータルZ](https://dailyportalz.jp/)，RSS `https://dailyportalz.jp/feed/headline`。
- 新闻及专题：[nippon.com](https://www.nippon.com/ja/)，RSS `https://www.nippon.com/ja/feed/`。
- 历史文化精选原文链接记录于 `tools/update_articles.py`。

仅整理文章标题、来源、日期、链接，不打包第三方全文或图片；原文版权属于各来源。分类依据来源与标题关键词，可能需要人工修正。抓取失败保留旧索引；全部来源失败时工作流报错而不发布伪更新。此项目无账号、广告、社区或学习打卡；打开外部网站后适用该网站自身的规则。

备份是本项目格式，与英语软件数据格式分开。卸载、清除网站数据或系统回收存储可能丢失本地学习记录，建议定期导出。
